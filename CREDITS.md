# Сведения о материалах

Navigator Map Scum — независимый проект NeDjin, не официальный продукт разработчиков SCUM.

Стандартная карта SCUM 1.2 собрана TripplExN и используется с опубликованного разрешения автора: [источник и разрешение](https://www.reddit.com/r/SCUMgame/comments/1rujbe4/scum_12_high_res_map_no_poismarkers_14k_x_14k/). Исходные игровые материалы принадлежат их правообладателям.

Изображения в README — снимки интерфейса тестовой сборки Navigator. Состояние карты, GPS и отметки приведены для демонстрации интерфейса.

Часть справочных координат ориентиров подготовлена на основе [CTsys SCUM Map Overlay](https://github.com/tahembre/SCUM_MapOverlay_v0.1), лицензия MIT. Текст лицензии включён в установщик. Координаты обычных и заброшенных бункеров сверены с [SCUM-MAP](https://scum-map.com/). Значки и сетка секторов нарисованы в Navigator; данные не показывают состояние дверей бункеров или изменения конкретного сервера.
